{{/* Citation block: the prose form, then BibTeX. Both are built from front matter plus the canonical URL, so neither can drift from the article. The copy button is the one permitted piece of JS and ships inline here so it reaches only pages that use this shortcode. */}} {{- $p := .Page -}} {{- $headline := $p.Params.h1 | default $p.Title -}} {{/* "Sudhamshu Addanki" -> "Addanki, Sudhamshu", overridable for names that do not split on the last space. */}} {{- $cited := site.Params.authorCitation -}} {{- if not $cited -}} {{- $parts := split site.Params.author " " -}} {{- $last := index $parts (sub (len $parts) 1) -}} {{- $given := delimit (first (sub (len $parts) 1) $parts) " " -}} {{- $cited = printf "%s, %s" $last $given -}} {{- end -}} {{- $surname := index (split $cited ",") 0 -}} {{- $key := $p.Params.citeKey -}} {{- if not $key -}} {{- $key = printf "%s%d%s" (lower $surname) $p.Date.Year (index (split $p.File.BaseFileName "-") 0) -}} {{- end -}} {{- $bibtex := printf `@article{%s, title = {%s}, author = {%s}, journal = {%s}, year = {%d}, month = {%s}, url = "%s" }` $key $headline $cited site.Title $p.Date.Year ($p.Date.Format "January") $p.Permalink -}}

Citation

Please cite this work as:

{{ $cited }}. “{{ $headline }}”. {{ site.Title }} ({{ $p.Date.Format "Jan 2006" }}). {{ $p.Permalink }}

Or use the BibTeX citation:

{{ $bibtex }}
